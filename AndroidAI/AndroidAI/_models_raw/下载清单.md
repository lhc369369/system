# 模型原始文件下载清单

下载后放到本目录(`E:\system\AndroidAI\_models_raw\`),不要直接放进 `app/src/main/assets/models/`。
原始权重需要先导出成 ONNX,再放进 assets。

## 1. SCRFD 人脸检测

- 页面:https://github.com/deepinsight/insightface/releases/tag/v0.7
- 下载:`buffalo_l.zip`(约 300 MB,解压后取 `det_10g.onnx`,即 SCRFD-10GF,输入 640x640,输出人脸框 + 5 关键点)
- 备选:`buffalo_s.zip`(小模型,手机更快,精度略低)

## 2. MiniFASNetV2 活体检测

- 仓库:https://github.com/minivision-ai/Silent-Face-Anti-Spoofing
- 文件:`resources/anti_spoof_models/2.7_80x80_MiniFASNetV2.pth`(约 1.7 MB,仓库自带)
- 直接下载:
  https://github.com/minivision-ai/Silent-Face-Anti-Spoofing/raw/master/resources/anti_spoof_models/2.7_80x80_MiniFASNetV2.pth

## 3. EdgeFace 人脸特征

- 仓库:https://github.com/otroshi/edgeface
- README 的 "Pre-trained models" 部分有 Google Drive 链接
- 需要的文件:`edgeface_xs_gamma_06.pt`(轻量版,适合手机)
- 下载后需要导出成 ONNX

## 网络提示

这台机器直连 GitHub Release / raw 会超时。浏览器打不开时,可以在链接前加国内镜像前缀:

    https://ghproxy.net/ + 原链接

例如:

    https://ghproxy.net/https://github.com/deepinsight/insightface/releases/download/v0.7/buffalo_l.zip
