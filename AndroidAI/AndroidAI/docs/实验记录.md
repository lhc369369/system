## 3. 优化前后对比(初步)

| 项 | 优化前 | 优化后 | 说明 |
|---|---|---|---|
| 检测模型 | det_10g(10 GFLOPs) | SCRFD-500M | 单帧 780 ms → 47 ms(叠加下面两项) |
| 输入张量构造 | 堆内 FloatBuffer | 直接缓冲 | 730 ms → 1 ms |
| 推理后端 | CPU | NNAPI(SCRFD) | run 时间 ~770 ms → 17–29 ms |
| 活体输入尺度 | 0–1 | 0–255 BGR | 恒判攻击 → 真/假正常分开 |

注:上表为工程调通阶段的单项对比,不是课程要求的正式对照实验;正式实验需固定条件、每组 5 轮以上并保存原始 CSV。

## 4. 已知问题与后续

- 活体对逆光、屏幕翻拍样本的稳定性需要采多轮数据统计,目前只有零散样本。
- 识别阈值 0.45 未做 ROC/阈值标定,需用本人多姿态样本测相似度分布。
- 未测打印照片/另一屏幕翻拍的攻击样本。
- 未采集 CPU 占用、内存、Perfetto trace;第 6–7 周需要补。
- 队列策略目前是客户端丢帧(KEEP_ONLY_LATEST + frameBusy),服务端 Semaphore 限流;若要对比"无界队列"需要另加一种配置。
